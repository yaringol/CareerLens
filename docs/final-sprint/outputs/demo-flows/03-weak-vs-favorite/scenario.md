# פלואו 03 - קו"ח חלש מול מועדף מסומן בכוכב

**מטרה:** להדגים את פיצ'ר המועדפים: מעלים קו"ח חלש, המערכת מציפה שקו"ח שמור (מסומן
בכוכב) משיג תוצאה טובה יותר, ובוחרים בו.

## קבצים

- `Sapir-Ohana-CV.pdf` - ה"חלש" שמעלים בדמו (מקור: `bootcamp-frontend-junior-weak`).
- `Noa-Shapiro-CV.pdf` - המועדף שינצח (מקור: `frontend-mid-strong`). אותו תחום (frontend)
  בכוונה - כדי שההשוואה תהיה משמעותית.
- `jd-frontend.txt` - תיאור המשרה.

## תנאים מוקדמים (חד-פעמי, בהכנת משתמש הדמו)

`Noa-Shapiro-CV.pdf` כבר הועלה בעבר, שמור אצל המשתמש, ומסומן בכוכב (עד 3 מועדפים -
מסמנים ב-Account או ב-Upload).

## צעדים

1. העלאת `Sapir-Ohana-CV.pdf` + ה-JD → ניתוח → ציון נמוך יחסית.
2. במסך התוצאות מופיעה ההשוואה האוטומטית (`bestSavedCv`): המועדף Noa-Shapiro עם ציון
   גבוה יותר.
3. בוחרים במועדף → מוודאים שהמערכת עוברת להצגת התוצאה הטובה.

## תוצאה צפויה

פער ציונים ברור (חלש vs מועדף), הצעת ההשוואה מופיעה מעצמה, והבחירה במועדף עובדת חלק.

## נפילות אפשריות

- ההשוואה לא מופיעה → לוודא שהכוכב אכן מסומן ושהניתוח באותו תחום; אם עדיין לא - באג,
  לדווח.
- הפער קטן מדי בשביל סיפור טוב → להחליף את החלש ב-`student-junior-weak_Itay-Cohen`
  מהקורפוס.
