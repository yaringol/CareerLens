# צ'קליסט סביבת production לדמו - למסירה לבעל הסביבה

**סביבה:** https://careerlens.cs.colman.ac.il
**הקשר:** M11 (מוכנות לדמו חי). הבדיקות ירוצו מול production ברגע שכל הסעיפים כאן
מסומנים והמשתמשת נותנת את האות.

## משתמש הדמו

- [ ] המשתמש `demo@careerlens.dev` קיים (אם לא - ניצור אותו דרך ה-UI; חלופה קיימת:
      `mail@mail.com`).
- [ ] למשתמש הדמו מוקצה `role: 'admin'` במסמך המשתמש ב-MongoDB (collection `users`,
      שדה `role`, ערכים `admin`/`user`; אין UI לזה - עדכון ישיר ב-DB).

## מודל ו-DS server

- [ ] **מודל 1 המאומן (28/07)** הוא הפרוס - לא גרסה ישנה עם דאטת סקילז ריקה.
- [ ] env ההגשה על ה-DS server: `UBIQUITY_CAP=11`, `ROLE_COUNT_MIN_PREVALENCE=0.05`.
- [ ] **הריצה הלילית לא דורסת את המודל הפרוס** (מוקש ה-volume מ-M06) - לוודא שהמודל
      שנטען אחרי לילה הוא עדיין הנכון.

## דאטה לטאב האדמין

- [ ] DB `jobs` (שממנו קורא פאנל ה-pipeline באדמין) מאוכלס בדאטה שנראה אמין: משרות
      עם תאריכים עדכניים, כמויות הגיוניות, ריצות pipeline נראות. **בלי זה מסך האדמין
      בדמו ריק.**
- [ ] אין ב-DB דאטת בדיקות מביכה שתופיע במסכי Admin / Account / Dashboard.

## כלליות

- [ ] המערכת נגישה מבחוץ (login עובד) והקריאות ל-LLM פעילות (מפתחות API בתוקף).
- [ ] אישור: מותר לנו להריץ העלאות וניתוחים של קבצי בדיקה מהמשתמש שלנו (ננקה אחרינו
      דרך ה-UI; לא נוגעים בדאטה של אף אחד אחר).

**כשהכל מסומן - להודיע למשתמשת, והיא נותנת לנו את האות להריץ את חמשת הפלואים.**
