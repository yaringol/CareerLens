# פלואו 01 - אדמין מלא

**מטרה:** להראות את טאב האדמין כ"וואו הנדסי" - המערכת אוספת ולומדת דאטה יומית.

## תנאים מוקדמים

- `demo@careerlens.dev` קיים ב-production עם `role: 'admin'` (צ'קליסט סביבה, סעיפים 1-2).
- DB `jobs` מאוכלס בדאטה אמין - פאנל ה-pipeline קורא ממנו (מוקש M07). בלי זה הפאנל ריק.

## צעדים

1. התחברות כמשתמש הדמו → מוודאים שקישור Admin מופיע בניווט.
2. כניסה ל-`/admin` → פאנל ה-pipeline נטען עם מספרים > 0 (משרות שנאספו, ריצות).
3. מעבר על הסקשנים: הנתונים נראים חיים ואמינים (תאריכים עדכניים, כמויות הגיוניות,
   בלי placeholder או שמות בדיקה מביכים).

## תוצאה צפויה

פאנל מלא בדאטה אמין; אפשר לספר בסיפור אחד: "המערכת רצה יומית, אוספת משרות, ומעדכנת מודל".

## נפילות אפשריות

- **פאנל ריק** → פער ה-DB לא טופל בסביבה. לא באג בקוד - לחזור לבעל הסביבה. אם לא נפתר
  עד יום השיפוט: מורידים את סעיף האדמין מהתסריט ומספרים את סיפור הלמידה במילים + figure.
- קישור Admin לא מופיע → `role` לא עודכן ב-DB.
