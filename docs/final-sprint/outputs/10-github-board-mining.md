## הערת גישה — מה נכרה ומה לא

- **לוח Projects v2: לא נמצא לוח ציבורי.** עמוד ה-Projects הציבורי של המשתמש `yaringol` ריק, ועמוד ה-Projects של הריפו אינו מציג לוחות לגולש אנונימי. אם קיים לוח פרטי — הוא לא היה נגיש (GitHub CLI אינו מותקן בסביבה, אין token, ושרת ה-MCP של GitHub נכשל באימות). Projects Classic: ‏404 (לא קיים).
- לכן "הלוח" משוחזר כאן מהשלד שכן קיים ונגיש בפומבי: **milestones (כעמודות-תכנון), issues (כמשימות/epics), ו-PRs (כעדות ביצוע)**. כל הטענות בקובץ מגובות במזהה.
