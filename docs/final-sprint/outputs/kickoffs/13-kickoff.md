## 4. תוכנית מימוש

1. **גיבוי בטיחות (לפני הכל):** `git clone --mirror` + `git bundle create` לתיקייה מחוץ
   לריפו. **אימות:** ה-bundle נפתח (`git bundle verify`).
2. **ניתוח `.gitignore`:** הסרת `*.md` הגורף; הוספת ignore ממוקד לפתקים הפרטיים:
   `docs/IMPLEMENTATION_PLAN.md`, `docs/JIRA_TASKS*.md`, `docs/milestone1-*.md`,
   `docs/mcp-prompts.md`, `docs/design-todo.md`, `docs/TASKS.md`, `docs/POC.md`,
   `LOGIN_QA_REPORT.md`, `QA_TEST_PLAN.md`, `CLAUDE.md`, `MEMORY.md`-דמויים אם יש.
   **אימות:** `git check-ignore` על כל פרטי → ignored; על התוכנית/הספר → לא.
3. **מעקב מפורש (קומיטים לוגיים, בלי זכר ל-AI בהודעות):**
   א. `scripts/check-git-lfs.js` (מתקן את ה-postinstall) — קומיט משלו.
   ב. `poc_files/` (בלי node_modules - ה-ignore הגלובלי מכסה).
   ג. `docs/final-sprint/` + `docs/progect_book/` + האפיון + `assets/` + `12-meeting-summary` + INDEX.md.
   ד. `test-fixtures/` (authentic-cvs 3.4MB + 3 ה-PDF הבודדים).
   **אימות לכל קומיט:** `git show --stat`, סריקה שאין `.env*`/סודות/קבצים אישיים.
4. **סקרינשוטים** (לפי הכרעת המשתמש בסעיף 7) - gitignore או העברה.
5. **נעילת Python:** שליפת הגרסאות מהאינטרפרטר שמריץ את ה-DS בפועל
   (`python -c "import sklearn,numpy,joblib;..."`) → pin שלושתן ב-`ds/requirements.txt`.
   **אימות:** venv נקי + `pip install` + `joblib.load` על שלושת המודלים מצליח.
6. **README מינימלי (סקופ M13 בלבד):** Prerequisites עם `git lfs install && git lfs pull`,
   ותיקון שורת ההתקנה השבורה (`requirements-server.txt` → הקובץ האמיתי). שאר התוכן - M02.
7. **ניקוי היסטוריית AI** (לפי ההחלטה מ-14/07: main בלבד, + הענף הנוכחי - ראה סעיף 2):
   `git-filter-repo --message-callback` על refs `main` + `final-submission-prep` בעותק
   mirror נפרד → force-push שניהם. לוודא ש-3 הקומיטים המקומיים-בלבד לא נדחפים לעולם.
   **עדכון 22/07 (ממצא כריית M10):** קומיט `8ea1878` ("fix: re-analyze via rescore...")
   בהיסטוריית main נושא trailer של `Co-authored-by: Cursor` - הרג'קס של הניקוי חייב לכסות
   גם אותו: `/Co-authored-by:.*(Claude|anthropic|Cursor)/i`.
   **אימות:** `git log origin/main --grep="Co-authored-by" -i` → 0 (תופס Claude וגם Cursor);
   אותו דבר על הענף;
   `git log --oneline` משמר את אותם קומיטים (רק הודעות השתנו).
8. **שער ה-clone הנקי (הבדיקה שקובעת):** clone לתיקיית temp → `git lfs pull` →
   `backend: npm install` → `frontend: npm install && npm run build` → `ds: venv + pip
   install + טעינת שלושת ה-joblibs`. כשל בכל שלב = חוזרים ומתקנים.
9. עדכון סטטוס במאסטר + דיווח (כולל סטטוס מכסת ה-LFS - דורש בדיקה שלך בהגדרות GitHub).

**נקודות עצירה בטוחות:** אחרי כל צעד; צעדים 1-6 הפיכים לחלוטין; צעד 7 מגובה ע"י צעד 1.
**Out of scope:** ניקוי 42 ענפי remote (דורש תיאום שותפים - יוצע ב-M12); תוכן README
(M02); כל שינוי קוד.

## 5. סיכונים ומיטיגציות

| סיכון | תרחיש | חומרה | מיטיגציה |
|---|---|---|---|
| force-push דורס עבודת שותפים | שותף דחף ל-main בין הגיבוי לדחיפה | גבוהה | תיאום לפני; הריצה כולה < שעה; mirror backup; לוודא `git fetch` טרי מיד לפני |
| ה-rewrite משנה SHA של קומיטים ב-main | PRs היסטוריים ב-GitHub יצביעו על SHA ישנים | בינונית-נמוכה | מקובל בניקוי כזה; ה-PRs נשארים קריאים; לתעד |
| חשיפת קובץ פרטי בהסרת `*.md` | פתק אישי שלא ברשימת ה-ignore הממוקד נהיה trackable | בינונית | צעד 2 כולל סריקת כל `.md` untracked לפני הקומיט + אימות check-ignore |
| pin שגוי של Python | pin לגרסה שאינה זו שיצרה את ה-pickle | בינונית | שליפה מהאינטרפרטר החי + אימות טעינה ב-venv נקי (צעד 5) |
| מכסת LFS נגמרת בדיוק בהגשה | בודק עושה clone והמודל מגיע כ-pointer | גבוהה אם קורה | דיווח בצעד 9; אם קרוב למכסה - החלטה נפרדת איתך (לא בסקופ לפתור כאן) |
| סקופ מתנפח | "עוד קובץ קטן" עד אינסוף | נמוכה | הרשימה בצעד 3 סגורה; כל תוספת = שאלה |
