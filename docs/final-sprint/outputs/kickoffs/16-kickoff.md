## 4. תוכנית מימוש

1. **`docs/architecture.md`** - מסמך קנוני באנגלית: פרוזה תמציתית + 3 בלוקי mermaid.
   מקור אמת יחיד לתיאור המערכת. **אימות:** כל רכיב/חץ מוצלב מול פרק 4 והקוד; אפס
   רכיבים "מתוכננים".
2. **דיאגרמה 1 - as-built architecture:** SPA → Node API (5 אגנטים בשמם) → DS server
   (2 מודלים + normalizer) → Mongo×2; חיבור ה-admin ה-read-only מסומן מקווקו; הערת
   פריסה: 5 קונטיינרים + pipeline (batch) + ofelia (cron).
3. **דיאגרמה 2 - פייפליין הדאטה:** scrape → SkillNer (persisted) → observations →
   train (אגרגציה+recency) → **promotion gate** (מודגש - הרעיון החזק) → serve/reject.
4. **דיאגרמה 3 - sequence מקצה לקצה:** upload → חילוץ+header window → סולם הזיהוי
   התלת-שלבי → personalize → analyze (5+5 → scoring agent → Match Score) → improve
   per-section. **בלי** מסך Gap Analysis (M15 טרם נבנה) - הדיאגרמות משקפות את הקיים.
5. **זוג תוכנן-מול-בוצע:** image2.png לצד דיאגרמה 1, עם כיתובים "As designed (spec,
   pre-implementation)" / "As built" - הפיגר החזק בספר.
6. **רינדור PNG** → `docs/final-sprint/outputs/diagrams/`: HTML מקומי עם mermaid +
   Edge headless screenshot (הצינור שהוכח ב-M04); fallback: `npx @mermaid-js/mermaid-cli`.
   סגנון: נייטרלי ידידותי-להדפסה (הספר מודפס), מונוכרום + accent אחד.
7. **כיתובים ממוספרים** תואמי Table of Figures של השלד (Fig.1-4) + עדכון ה-placeholders
   בפרקי הספר לשמות הקבצים.
8. **אישור המשתמש:** הצגת הדיאגרמות - "זו המערכת?" - לפני שהספר נשען עליהן.

**עצירה בטוחה:** אחרי כל דיאגרמה. **Out of scope:** דיאגרמות תוצאות (M05), סקרינשוטים
(M08), כל שינוי קוד, כל פקודת git (הנחיה פעילה - כתיבת קבצים בלבד).
