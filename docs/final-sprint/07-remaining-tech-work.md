## איך לעבוד

1. **שלב אימות (לפני הכל):** לכל פריט שאושר - לקרוא את הקוד הרלוונטי ולכתוב שורת סטטוס:
   "קיים מלא / קיים חלקי (חסר X) / לא קיים". להציג למשתמש את הפער בין המסמכים למציאות.
2. לממש לפי ההנחיות המפורטות במסמכי המקור (08 מכיל קונטרקטים מדויקים של JSON, מיקומי קוד,
   ודפוסים קיימים לחיקוי - `matchTitle`/`extractTitleFromCv` כתבנית ל-proxies וכו').
3. כל פריט - קומיט נפרד + אימות עצמאי (ה-Verification בסוף מסמך 08 מפרט איך לאמת כל פריט).
4. בדיקות UI - עם Playwright MCP.
