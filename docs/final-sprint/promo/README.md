## שלושת הכללים שחוזרים בכל המסמכים

1. **האווירה קודמת לטכניקה.** קשת הרגש היא: הצפה → תסכול → **שקט** → תקווה → הקלה.
   השקט בשנייה 0:39 (אחרי שכדור הנייר נוחת בפח) הוא הרגע החזק בסרטון. אל תקצרי אותו.
2. **מסכי המוצר תמיד אמיתיים.** מודל AI יידע לרנדר UI משכנע, אבל ימציא ציונים ומיומנויות
   שהמוצר לא מייצר. בשוטים המופשטים (2, 4) — כן לבקש טקסט, המודלים החדשים מרנדרים אותו היטב.
3. **שוט 6 ושוט 12 = אותו אדם, אותו חדר, אותה זווית.** זו כל הפואנטה של הסרטון.
   ייצרי את שוט 6 קודם, שמרי ממנו פריים, והשתמשי בו כעוגן לכל שאר שוטי הדמות.
